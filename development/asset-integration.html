Integration gates

  1. Compare production and GitHub game versions.
  2. Import originals without overwriting source artwork.
  3. Verify frame sizes, transparency, alignment and animation timing.
  4. Integrate approved sprites into the game.
  5. Test on laptop and Android phone.

Tire Shots Rival uses separate idle, walk, and attack frames for Hector and Erasmo. Original source sheets and production frames are inventoried separately.
